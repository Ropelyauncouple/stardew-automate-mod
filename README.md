# Automate

### Automate your Stardew Valley farm with machines

Automate is a Stardew Valley mod that connects machines, chests, and crops into fully automated networks. Place a chest next to any machine and watch it fill with inputs and empty its outputs — farming on autopilot.

<br>

---

## Features

| | |
|:---|:---|
| **Machine Networks** | Connect any combination of machines into self-feeding production chains |
| **Smart Routing** | Outputs automatically route to connected chests based on item type |
| **Junimo Huts** | Automate Junimo huts for hands-free crop harvesting across your farm |
| **Config Flexibility** | Fine-tune which machines automate and how they prioritize inputs |
